## Что делаем

Сгенерируем по одной обложке для каждого из 6 кейсов (16:9, премиум-стиль в духе сайта — тёмный фон, неоновые акценты, glassmorphism), подключим их к данным и выведем на превью-карточках и в hero детальной страницы.

## Изображения

Генерируем через `imagegen--generate_image` (model: `standard`, 1280×720, без прозрачности) в `src/assets/cases/`:

| Файл | Кейс | Промпт-направление |
|---|---|---|
| `samokat-szfo.jpg` | AI-диспетчер заявок | Абстрактная визуализация потоков сообщений в виде светящихся линий, сходящихся в нейронный узел; тёмно-синий фон, циан/индиго акценты |
| `domteh.jpg` | Telegram-бот стройматериалов | Telegram-интерфейс на фоне строительных текстур, неоновые карточки товаров, синий glow |
| `ayboit.jpg` | Голосовой AI-администратор | Звуковая волна + медицинский крест из света, мягкий бирюзовый/индиго градиент |
| `ecomarket.jpg` | B2B-портал | Изометрический дашборд с графиками поставок, тёмный UI, светящиеся узлы сети |
| `promlogistika.jpg` | OCR + RPA | Документы превращаются в потоки данных, OCR-сетка поверх накладной, неоновый акцент |
| `yasno.jpg` | AI-тьютор | Открытая тетрадь с подсвеченными формулами, частицы знаний, мягкое свечение |

Все обложки — единый visual language: тёмный фон #0a0a1a, акцент primary/accent сайта, лёгкий grain, без текста на изображении.

## Изменения в коде

- **`src/data/cases.ts`** — добавить поле `cover: string` в интерфейс `CaseStudy`, импортировать каждую картинку и присвоить в записях. Импорт ассетов как ES-модулей (`import samokatCover from "@/assets/cases/samokat-szfo.jpg"`).
- **`src/components/sections/Cases.tsx`** — добавить `<img>` сверху карточки (16:9, `object-cover`, скруглённые углы, лёгкий градиент-overlay снизу), сохранить иконку поверх обложки в углу. `loading="lazy"`, `alt` = `${client} — ${title}`.
- **`src/routes/cases.$slug.tsx`** — добавить hero-изображение под заголовком (full-width внутри max-w-5xl, 16:9, рамка glass, мягкое свечение). В блоке «Другие кейсы» — миниатюра в каждой карточке. В `head()` добавить `og:image` и `twitter:image` (абсолютный URL не критичен — TanStack отдаст путь, либо выставим относительный путь от ассета).

## Технические детали

- Vite превратит импорт `@/assets/cases/*.jpg` в финальный URL — это работает и для og:image (значение `study.cover` будет хешированный путь).
- Размер каждой картинки ~1280×720, итог JPG ≤ 200KB после оптимизации Vite.
- Никаких изменений в БД, маршрутах, формах.

## Что НЕ делаем

- Не трогаем дизайн остальных секций.
- Не делаем галерею из нескольких изображений на кейс — одна обложка.
- Не переключаемся на внешний CDN.
